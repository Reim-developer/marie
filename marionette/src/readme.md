# Marionette

**What's Marionette?**
* Marionette is a sub-project of Marie. It's a command line tool that allows to create HTML templates with images based on a specific configuration called: ".marionette.toml".
* It is currently under development and is an internal tool for the entire project. Of course, the future Marionette won't be limited just HTML and images. But it will always be based on the requirements of main project and it's author, Scheherazade.
